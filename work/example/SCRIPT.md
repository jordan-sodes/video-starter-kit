Format: landscape · Length: about 30 s · Voice: Charlie (from brand.json)

## Decided

- "makes the voiceover", not "records the voiceover" ("records" can be read as the noun).

## Accuracy notes

- "Your first one takes an afternoon": true for a 30–60 s video once set up; setup adds about 15 minutes.
